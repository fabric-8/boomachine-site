# Boo Machine site

Public support, privacy and (soon) press pages for Boo Machine, published via GitHub Pages at https://fabric-8.github.io/boomachine-site/.

- `index.html` – landing
- `support.html` – app support
- `privacy.html` – privacy policy
- `press/` – press kit (ZIP; `press/index.html` redirects to it)
- `drafts/<iteration>/` – unlisted staging copies of new site iterations
- `subscribe.php`, `confirm.php`, `unsubscribe.php`, `notify-admin.php` – the launch list (double opt-in email sign-up); see `README-NOTIFY.md`

Sources, plans and the press-kit build live in the app repo (`../app/docs/marketing/halloween-2026/`); the umbrella folder `..` has the project map in `CLAUDE.md`.
